# 人体図3D

皮膚・筋肉・骨を、指やマウスで回しながら好きな角度から見られる人体図です。
皮膚と筋肉の透け具合はスライダーで変えられます。

## 使い方

- **iPad / iPhone**：Safari でこのページを開き、共有メニューから「ホーム画面に追加」
- **Mac**：Safari でこのページを開き、メニューの「ファイル」→「Dock に追加」
- 1本指（マウスはドラッグ）で回転、2本指（マウスはホイール）で拡大、2本指のドラッグ（マウスは右ドラッグ）で移動

一度開くとモデルが端末に保存され、電波がなくても使えます。

## 注意

学習用の図です。動作を軽くするため、元の3Dデータより形を簡略化しています。体表の一部は計算で改変しています。
